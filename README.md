# 📊 Sistema de Notas em JavaScript

Projeto simples desenvolvido para praticar lógica de programação com JavaScript.

O programa recebe as notas de **3 alunos**, armazena os valores em um array e calcula informações básicas do boletim.

## 🚀 Funcionalidades

- Solicita 3 notas usando `prompt()`
- Armazena as notas em um array
- Exibe a nota de cada aluno no console
- Calcula a soma das notas
- Calcula a média das notas

## 🧠 Conceitos praticados

- Arrays
- `for`
- `prompt()`
- `Number()`
- `.push()`
- Contadores
- Acumuladores
- Cálculo de média

## 🛠️ Tecnologias

- HTML5
- JavaScript

## ▶️ Como executar

1. Abra o arquivo `index.html` no navegador.
2. Digite as três notas solicitadas.
3. Abra o console do navegador para visualizar as notas, a soma e a média.
